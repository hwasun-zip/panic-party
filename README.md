# PANIC PARTY

> 파티원 5명과 함께 가면무도회의 보스 '마스케라'를 깨는 2D 웹 액션 게임
> 화려한 파티 전투 속에서, 피해야 할 공격은 얼마나 잘 보일까?

**플레이:** https://hwasun-zip.github.io/panic-party/ (PC, 키보드, 크롬 추천, 약 5분)

## 한 줄 소개
파티원 스킬과 연출이 화면을 가득 채우는 전투에서, 플레이어가 위험한 공격을 알아보고 피할 수 있는지 직접 실험하기 위해 만든 게임입니다.

## 왜 만들었나
파티 액션 게임 영상을 처음 봤을 때, 파티원 스킬이 화면을 덮는 순간 캐릭터가 왜 맞았는지 알 수 없었습니다. 이 "왜 죽었지?"를 줄이는 방법을 말로 설명하는 대신, 같은 상황을 게임으로 만들어 플레이 기록으로 확인하기로 했습니다.

## 진행 구조 (한 판 약 5분)
튜토리얼 → 라운드 1 → 질문 2개 → 라운드 2 → 질문 2개 → 마지막 질문

| 구역 | 시간 | 미션 | 특징 |
|---|---|---|---|
| 1구역 정원 테라스 | 최대 18초 | 하인 가면 6개 깨기 | 적과 싸우며 기본 조작 익히기 |
| 2구역 무도회장 | 최대 14초 | 10초 동안 피하기만 | 적 없이 패턴만 나오는 피하기 구간 |
| 3구역 무대 | 최대 40초 | 마스케라의 가면 깨뜨리기 | 보스전, 빈틈과 분노 2페이즈, 빈틈에 황금 망치 |

## 조작
← → 이동 / ↑ 점프 / X 대시(잠깐 무적) / Z 베기 / C 회전 베기 / V 황금 망치(판마다 2번)

## 플레이 테스트
- 두 라운드는 패턴, 적, 이펙트 양, 난이도가 모두 같고 **딱 한 가지 규칙만 다릅니다.** 무엇이 다른지는 테스트가 끝난 뒤 이 문서에 공개합니다.
- 라운드 순서는 사람마다 무작위로 정해집니다(학습 효과를 상쇄하기 위해).
- **주 지표:** 위험 공격에 맞은 비율 = (맞은 횟수 + 보호막이 막은 횟수) ÷ 만난 위험 공격 수
- **보조 지표:** 미션 결과, 쓰러진 횟수, 중간 이탈 지점, 설문(나를 놓친 정도, 구분하기 쉬운 정도, 선호)
- **기록:** 무작위 ID만 사용하며 이름이나 이메일 같은 개인 정보는 받지 않습니다. Google Apps Script를 거쳐 구글 시트에 쌓입니다.
- **개발자 기록 분리:** `?debug=1`로 연 판은 기록에 표시되어 분석에서 제외합니다. 개발에 쓴 컴퓨터의 기록도 제외합니다.

## 기술
- Phaser 3.90, HTML 파일 하나(`index.html`), GitHub Pages 배포
- 로그 수신: Google Apps Script 웹 앱 → 구글 시트 (`sheet/Code.gs`)
- 그래픽은 모두 코드로 그린 오리지널 도형입니다.

## 역할 분담
- **기획자(본인)가 결정:** 컨셉, 테스트할 질문, 규칙, 난이도 방향, 무엇을 넣고 뺄지, 플레이 피드백
- **AI(Claude)가 담당:** 선택지 제안, 코드 구현, 버그 수정, 플레이 기록 분석 보조
